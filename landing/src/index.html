The same terminal, from either side.

pairmux is a small Agent-Computer Interface over tmux. Give an agent a real, persistent terminal. When a prompt needs credentials or a judgment call, a human can attach, take over, and hand it back.

Install pairmux Read the docs
  • Real PTYs for REPLs, TUIs, and interactive prompts.
  • Shell state that stays put between commands.
  • Shared observation and retained terminal history.

Not another exec API. Keep your built-in shell tool for quick, one-shot commands. Use pairmux when the terminal, its state, or a person is part of the work.

Install from PyPI.

With uv installed, add a persistent pairmux command for everyday use. The native binary is packaged on PyPI.

macOS, Linux, or a WSL shell

uv tool install pairmux

Ensure uv’s tool-bin directory is on your PATH, then run pairmux version and pairmux doctor.

Manual uv commands honor your normal environment and configuration. The built-in updater and shell installer instead pin pairmux’s source to public PyPI and ignore uv package-source overrides.

Separate requirements: Python 3.9 or newer for the uv tool environment; tmux 3.2 or newer to run terminals. Install tmux with your OS package manager. On Windows, pairmux runs inside WSL, not natively.

Keep it up to date.

Update your uv installation (v0.6.0+)

Install the latest compatible stable wheel from public PyPI. This only updates the persistent uv installation running this command, not Homebrew, RPM, or manual installs.

pairmux update

On v0.5.3 or earlier, once v0.6.0 is available, run uv tool install --upgrade pairmux first to obtain the new command. Updating resets old pins and source settings; the same version is reinstalled if already current.

Alternative: let the installer set up uv

curl -fsSL https://pairmux.treeleaves30760.com/install.sh | bash
